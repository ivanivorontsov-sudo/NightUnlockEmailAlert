# Night Unlock Email Alert

Android-приложение, которое отправляет уведомление на указанную электронную почту, если телефон разблокирован в период с **00:00 до 07:00**.

## Возможности

- Обнаружение разблокировки экрана (`Intent.ACTION_USER_PRESENT`)
- Проверка времени (с 00:00 до 07:00 по локальному времени устройства)
- Отправка email через SMTP (поддерживается Gmail)
- Настройка адреса получателя и учётных данных отправителя
- Фоновая работа с foreground-сервисом и постоянным уведомлением Android
- Автозапуск после перезагрузки устройства
- Минимальный набор разрешений без запроса на отключение оптимизации батареи

## Важно ⚠️

Приложение предназначено для контроля собственного устройства или устройства, владелец которого явно согласился на мониторинг.

Приложение не пытается скрывать свою работу от системы: мониторинг выполняется через foreground-сервис с постоянным уведомлением. Это сделано намеренно для прозрачности и уменьшения ложных срабатываний защитного ПО.

Для отправки почты через Gmail нужен **пароль приложения** (App Password), а не обычный пароль аккаунта.

## Как получить пароль приложения Gmail

1. Включите двухфакторную аутентификацию в Google-аккаунте.
2. Перейдите в Google Account → Security → App passwords.
3. Создайте пароль для «Mail» / «Other».
4. Используйте 16-символьный пароль в приложении.

## Сборка APK

### Через GitHub Actions (рекомендуется)

1. Перейдите во вкладку **Actions**.
2. Выберите workflow **Build APK**.
3. Нажмите **Run workflow** или дождитесь автоматической сборки после push в `main`.
4. После завершения скачайте APK из артефактов.

### Локально

```bash
git clone https://github.com/ivanivorontsov-sudo/NightUnlockEmailAlert.git
cd NightUnlockEmailAlert
./gradlew assembleDebug
```

APK будет в `app/build/outputs/apk/debug/app-debug.apk`

## Установка и настройка

1. Установите APK (разрешите установку из неизвестных источников, если это требуется устройством).
2. Откройте приложение.
3. Заполните поля:
   - **Email получателя** — куда слать уведомления
   - **Email отправителя** — ваш Gmail
   - **Пароль приложения** — 16-символьный пароль
4. Нажмите **Сохранить и запустить**.
5. Разрешите уведомления.
6. Готово. При разблокировке телефона с 00:00 до 07:00 на почту придёт письмо.
